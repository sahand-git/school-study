# 📱 ئامادەیا (Amadeya Flutter Mobile App)
### ئەپڵیکەیشنی پێشکەوتووی مۆبایل بە فلاتەر بۆ ئەزموونە وزارییەکانی پۆلی ١٢ (بەشی زانستی)

ئەم ئەپڵیکەیشنە بە **Flutter** دروستکراوە بە تایبەت بۆ بەدەستهێنانی نمرەی ٩٥٪ تا ١٠٠٪ لە تاقیکردنەوە وزارییەکانی هەرێمی کوردستان.

---

## 🌟 تایبەتمەندییە سەرەکییەکان (Features)

### ١. فێرکاری بنەماکان بە ٦٠ چرکە (Bite-Sized Lessons)
- لە پێش هەموو پرسیارێک، یاساکان (وەک یاسای ئۆم، داتاشراو، سنوور، پێوەری pH، یاسای مێندڵ) بە نموونەی ژیانی ڕۆژانە و بە ٣ خاڵی زێڕین بە سادەیی فێری قوتابی دەکرێت.

### ٢. شیکاری پرسیاری وزاری بە فێڵ و تەڵەی وزاری (Simplified Wezari Archive)
- هەموو پرسیارێکی خولەکانی وزاری پێکدێت لە:
  - دەقی پرسیار بە فۆنتی کوردی Vazirmatn.
  - **شیکاری بە سادەیی (Simple Explanation)** هەنگاو بە هەنگاو.
  - **💡 فێڵی وزاری (Exam Trick)** بۆ ئەوەی لە کەمتر لە ٢٠ چرکە وەڵام بدەیتەوە.
  - **⚠️ تەڵەی باو (Common Trap)** ئەو هەڵەیەی زۆربەی قوتابییان لە هۆڵەکەدا دەیکەن.

### ٣. مامۆستای زیرەکی تایبەت (Ask AI Tutor & Simplify)
- ئەگەر قوتابی تێنەگەیشت، بە یەک کلیک دوگمەی **"تێنەگەیشتم! بە سادەتر ڕوونی بکەرەوە"** دادەگرێت و مامۆستاکە بابەتەکە دەشکێنێتەوە بۆ ڕوونکردنەوەیەکی زۆر سادە.

### ٤. ئەنیمەیشن و ڕووکاری سەرنجڕاکێش (Cool UI/UX & Animations)
- ئاگری ستریکی ڕۆژانە (Animated Fire Streak) بە پڵسی درەوشاوە.
- ئەڵقەی نمرەی پێشبینیکراو (Animated Progress Ring).
- ئەنیمەیشنی کۆنفێتی و بەرزبوونەوەی دڵخۆشی (Confetti Particle Burst) لە کاتی وەڵامی ڕاست.
- لەرزینەوە (Shake Animation) و دڵنەوایی لە کاتی وەڵامی هەڵە.
- ڕووکاری تەواو شوشەیی (Dark Glassmorphism) و ئاراستەی کوردی سۆرانی (RTL).

### ٥. تاقیکردنەوەی خولی وزاری (Mock Exam Simulation)
- هاوشێوەی هۆڵی تاقیکردنەوە بە کاتژمێری دیاریکراو (١٢ خولەک)، تێکەڵکردنی پرسیار، نەخشەی پرسیار و دەرهێنانی نمرەی کۆتایی.

## 🚀 چۆن لەسەر کۆمپیوتەرەکەت دایمەزرێنیت و کاری پێبکەیت؟

### هەنگاوی ١: دابەزاندنی Flutter
ئەگەر فلاتەر لەسەر ئامێرەکەت نییە، لە ڕێگەی PowerShell (یان پەڕەی فەرمی فلاتەر flutter.dev) دایبەزێنە:
```powershell
winget install Flutter.Flutter
```
یان دەتوانیت پەڕگەی زیپی فلاتەر لە `https://storage.googleapis.com/flutter_infra_release/releases/stable/windows/flutter_windows_stable.zip` دابەزێنیت و بیخەیتە ناو `C:\flutter`.

پاشان فلاتەر بخەرە ناو PATH:
```powershell
$env:Path += ";C:\flutter\bin"
```

### هەنگاوی ٢: ڕاکێشانی پاکێجەکان
لەناو فۆڵدەری پڕۆژەکەدا بنووسە:
```powershell
cd "C:\Users\Lenovo\.gemini\antigravity\scratch\amadeya_flutter"
flutter pub get
```

### هەنگاوی ٣: کارپێکردن (Run)
بۆ کارپێکردن لەسەر مۆبایلی ئەندرۆید یان کۆمپیوتەر:
```powershell
flutter run
```

### هەنگاوی ٤: دروستکردنی فایلی APK بۆ مۆبایل
بۆ ئەوەی ڕاستەوخۆ فایلی APK دروست بکەیت و بیدەیتە دەست قوتابییان:
```powershell
flutter build apk --release
```
فایلەکە دەچێتە ناو:
`build/app/outputs/flutter-apk/app-release.apk`
